# 유튜잼 (YOUTUJAM)

떨어지는 노트를 박자에 맞춰 치는 웹 건반 리듬 게임입니다. 2000년대 PC방에서 하던 온라인 리듬 게임의 손맛을 떠올리며 새로 만들었습니다.

**하러 가기:** https://mhyoo-games.github.io/youtujam/

## 할 수 있는 것

- **세 가지 방식** (곡 고르기에서 Tab으로 바꾸기, 같은 곡·같은 채보로):
  - **건반**: 떨어지는 노트를 4·5·6·7건반으로
  - **망치**: 벨트를 타고 오는 못을 모루 위에서 내려칩니다. 파란 작은 못은 왼손(F) 작은 망치, 빨간 큰 못은 오른손(J) 큰 망치, 긴 판자는 꾹 눌러 리벳을 차례로 박기
  - **궤도**: 해와 달이 서로 번갈아 축이 되어 빙글 돌며 길을 따라갑니다. 도는 별이 다음 칸에 닿는 순간 아무 키나. 한 박이면 곧게, 반 박이면 직각으로 꺾여서 길 모양이 곧 리듬. 어려움에서는 ↺ 칸부터 반대로 돕니다
- 쉬움·보통·어려움 (곡마다·방식마다 Lv 숫자)
- **자체곡 4곡** (팝·일렉트로·시티팝·8비트 록): 브라우저가 실시간으로 연주합니다. 노트를 치면 그 음이 나고(키음), 놓치면 그 소리가 빠집니다.
- **클래식 9곡**: 저작권이 끝난 곡을 리듬 게임용으로 짧게 편곡 — 쇼팽 즉흥환상곡, 포레 시칠리안느, 오펜바흐 호프만의 뱃노래, 모차르트 터키 행진곡, 그리그 산왕의 궁전에서, 림스키코르사코프 왕벌의 비행, 워크 할아버지의 낡은 시계, 베토벤 운명 교향곡, 라벨 볼레로(3박자). 피아노·플루트 소리와 반주도 코드로 합성합니다.
- **잼 게이지**: 잘 칠수록 차오르고, 가득 차면 잼 콤보가 올라 점수가 더 붙습니다. 한 번 놓치면 처음부터.
- **유튜브 음악으로 하기**: 영상 주소를 붙여 넣고 노래를 들으며 채보를 녹음합니다. **리듬 채보**는 노트가 나올 때마다 키 하나만 치면(길게 누르면 길게) 박자는 그대로 두고 건반 칸을 자동으로 짜 줘서, 한 번 녹음으로 4~7건반·모든 난이도를 할 수 있습니다. 건반까지 직접 정해서 칠 수도 있습니다. 한 영상에 채보를 여러 개 만들 수 있고, 덮어쓰지 않습니다. (BPM·첫 박으로 만드는 대충 박자 채보도 있습니다.)
- **내 영상 목록**: 불러온 영상과 녹음한 채보는 이 브라우저에 쌓여, 다른 노래를 해도 지워지지 않고 언제든 목록에서 다시 꺼낼 수 있습니다. 백업 파일로 내보내고 가져올 수 있어 브라우저를 바꿔도 옮길 수 있습니다.
- **타건감**: 누르는 순간 나는 타격음 4가지(톡·딱·착·쿵)와 크기, 판정마다 다른 불꽃, 판정 오차 막대와 FAST/SLOW 표시, 끝나면 평균 오차를 알려 주고 한 번에 판정 맞추기에 반영
- **판정 자동 맞추기**: 삑 소리에 맞춰 16번 누르면 내 버릇(늦게/일찍)을 재서 판정을 맞춥니다.
- **휴대폰 모드**: 손가락 기기면 화면을 가로로 꽉 채우고, 판이 화면 너비 전체로 넓어져 아래쪽 누르는 칸이 큼직해집니다. 칠 때 진동(안드로이드), 전체 화면 버튼, 모든 메뉴를 눌러서 조작. 아이폰은 "홈 화면에 추가" 안내를 보여 주고, 홈 화면에서 열면 노치를 피해 꽉 찬 화면으로 열리며 무음 모드에서도 소리가 납니다.
- 길게 누르기 노트, 체력, 등급(SS~F), 최고 기록 저장

## 조작

| 건반 | 키 |
| --- | --- |
| 4 | D F J K |
| 5 | D F Space J K |
| 6 | S D F J K L |
| 7 | S D F Space J K L |
| 망치 | 왼손 A S D F (작은 망치) · 오른손 J K L ; Space (큰 망치) — 휴대폰은 화면 왼쪽·오른쪽 반 |
| 궤도 | 아무 키나 — 휴대폰은 화면 아무 데나 |

곡 고르기: ↑↓ 곡, ←→ 난이도, Tab 방식·건반 수 (4→5→6→7건반→망치→궤도), Enter 시작. 하는 중 Esc 잠깐 멈춤.

## 만든 방법

- TypeScript + Canvas 2D + Web Audio, esbuild로 묶음
- 곡·효과는 코드로 합성하고, 그림은 코드와 Kenney UI Pack으로 그립니다
- 채보·판정·점수 규칙은 화면과 떼어 Node 테스트로 확인합니다 (GitHub Actions)
